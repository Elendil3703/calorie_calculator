    云同步 未启用

    填入 GitHub Token 和 Gist ID 后，两台设备间会自动同步。不填则只在本地存储。

    如何获取 Token？
    1. 登录 GitHub → 右上头像 → Settings
    2. 左侧最下 → Developer settings → Personal access tokens → Tokens (classic)
    3. Generate new token (classic)，名字随便填，过期时间建议 No expiration
    4. 权限只勾 gist 这一个
    5. 生成后复制 token（只显示一次），粘到上面输入框
    6. Gist ID 第一次留空，保存后会自动创建并把 ID 填回到框里；在另一台设备配置时，把同样的 Token 和 Gist ID 填进去就能同步
